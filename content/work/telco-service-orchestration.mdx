## Context

Three product lines, dozens of downstream systems, regulated change windows.
The legacy flow lived in code nobody could read end to end, and a failed step
could leave an order half-provisioned without anyone noticing.

## Decision

Treat the process as a first-class artifact: BPMN in an engine, every side
effect an event on a log, .NET services behind stable contracts, and a trace
id that follows an order through every hop.
