AI can write the code now. Two things it cannot do for you: state your intent
precisely, and prove the result is right. Value moved to the edges — and that
is where I work.

## The path of a change

<Flow
  title="The path of a change"
  steps="Manifest: intent, versioned | Contracts: OpenAPI · AsyncAPI | Code: generated + human | Gate: drift · contract tests | Deploy: traced in prod | Evidence: back to the manifest"
  notes="Intent is written down first, versioned with the code. | Contracts are derived from the manifest, never hand-edited. | Code is generated and completed by people; the manifest still rules. | The gate: deterministic checks, no model in the loop. Fail → back to code. | Deploy carries a trace id that links every hop to the order. | Evidence flows back: what production saw becomes the next manifest change."
/>

The gate is the interesting part. It is deterministic: no model decides
whether the code still matches the manifest, a checker does. Try it.

## Seven principles

Each one is a rule I can be held to.

1. Intent is the product; code is a by-product.
2. A spec you can't check is a wish.
3. Tests are a contract with the future.
4. AI works inside the guardrails, not around them.
5. Make the right thing the default.
6. Proof over promises.
7. Humans own decisions; tools own repetition.
