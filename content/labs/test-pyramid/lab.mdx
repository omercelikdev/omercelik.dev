When code is expensive, the pyramid is wide at the bottom because unit tests
are the cheapest evidence you can buy. When code is nearly free, the cheap
evidence is also nearly free to fake — and the layers that talk to something
real (contracts, integration, production signals) carry the weight.

This is a sketch, not a measurement. The real version will be fed by the test
inventory of an actual repository.
